# Whisk 🍳

A Flutter chatbot that helps you decide what to cook. Tell it what meal you're
making (breakfast, lunch, dinner, or snack) and what ingredients you have on
hand, and it suggests a dish along with a recipe — powered by the Gemini API.

## Features

- Chat interface built with `dash_chat_2`
- AI-guided conversation (asks for meal type + ingredients if you haven't said)
- Multi-turn context, so it remembers earlier answers in the conversation
- Typing indicator while waiting on a response
